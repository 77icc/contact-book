# 通讯录 Contact Book

软件工程（福大–MU）极限编程作业：一个纯前端的通讯录应用，支持联系人收藏、多联系方式录入与 Excel 导入导出。

## 功能

| 功能 | 说明 | 对应分值 |
| --- | --- | --- |
| 联系人收藏 | 星标收藏 / 取消收藏，收藏联系人置顶显示，支持“只看收藏”筛选 | 25 分 |
| 多联系方式 | 同一个联系人可录入手机号、邮箱、社交账号、住址、备注 | 10 分 |
| 导入导出 | 导出为 `.xlsx`，一人一行、每项信息单独一列；按表头解析 Excel 并新增联系人 | 25 分 |
| 页面样式 | 黑白灰极简风格，响应式布局，悬停 / 弹窗 / Toast 交互反馈 | 10 分 |

## 运行方式

无需 Node、无需数据库、无需构建：

1. 克隆或下载本仓库；
2. 双击 `index.html`（推荐使用 Chrome / Edge 打开）即可使用。

数据保存在浏览器 `localStorage` 中，刷新页面不会丢失。

## Excel 格式

导出 / 导入使用同一套表头：

| 姓名 | 是否收藏 | 手机号 | 邮箱 | 社交账号 | 住址 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 张三 | 是 | 13800138000 | zhangsan@example.com | 微信 zhangsan_wx | 福建省福州市 | 同组队友 |

- 导出：一人一行，每一项信息单独占一列；
- 导入：第一行为表头，`姓名` 为空的行会被跳过，其余行追加为新联系人。
