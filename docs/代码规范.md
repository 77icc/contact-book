# 代码规范

本项目的代码规范参考《阿里巴巴前端代码规范》与 Airbnb JavaScript Style Guide，并结合本作业规模做了简化。

参考链接：

- 阿里巴巴前端代码规范：https://github.com/airbnb/javascript
- HTML / CSS 规范：https://codeguide.bootcss.com/

## 1. 命名

| 类型 | 规范 | 示例 |
| --- | --- | --- |
| 变量 / 函数 | 小驼峰 | `getVisibleContacts`、`importExcel` |
| 常量 | 全大写 + 下划线 | `STORAGE_KEY`、`EXCEL_HEADERS` |
| CSS 类名 | 小写 + 中划线 | `.card`、`.star-btn`、`.is-fav` |
| DOM id | 小驼峰 + 语义后缀 | `searchInput`、`exportBtn` |
| 文件 | 小写 + 中划线 | `app.js`、`代码规范.md` |

## 2. 缩进与排版

- 统一使用 2 个空格缩进，不使用 Tab；
- 每行不超过 120 个字符；
- 语句必须以分号结尾；
- 字符串统一使用单引号。

## 3. 注释

- 文件头部说明模块职责；
- 函数上方用 `/* ==== 分区 ==== */` 标注功能区块；
- 注释解释“为什么”，不复述“做了什么”。

## 4. JavaScript

- 采用 IIFE + `'use strict'` 隔离作用域，避免污染全局；
- DOM 查询集中在 `els` 对象中，避免重复查询；
- 数据变更后统一走 `saveContacts()` + `render()`，保证视图与存储一致；
- 事件回调使用具名函数，便于调试。

## 5. CSS

- 颜色、圆角等公共值统一用 CSS 变量定义在 `:root`；
- 类名扁平化，不嵌套超过两层；
- 交互状态（`:hover`、`:focus`、`.active`）与基础样式写在一起，便于查找。

## 6. Git 提交规范

提交信息采用 `type: 描述` 格式：

| type | 含义 |
| --- | --- |
| feat | 新增功能 |
| fix | 修复缺陷 |
| style | 样式调整 |
| docs | 文档变更 |
| refactor | 重构 |

示例：`feat: 支持联系人收藏与只看收藏筛选`
